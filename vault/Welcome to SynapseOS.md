# ❖ Welcome to SynapseOS Knowledge Vault

This is your local **Second Brain** knowledge base. All Markdown files placed in this directory are automatically indexed into vector embeddings for instant semantic search, AI context retrieval, and 3D neural visualization.

## Key Capabilities
- **Semantic RAG**: The AI agent queries your notes in real time using local vector embeddings.
- **Bi-directional Links**: Connect concepts with `[[WikiLinks]]` to build an associative knowledge graph.
- **Categorization**: Group notes using tags like `#architecture`, `#security`, `#ai`, and `#notes`.

## Getting Started
1. Place your existing Obsidian vault or Markdown notes directly into this directory (`./vault`).
2. Open the **Knowledge Graph** in the UI to explore concepts in 3D.
3. Chat with your AI Agent — it will cite and reason over your notes!
